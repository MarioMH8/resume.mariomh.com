# Security policy

## Supported versions

Security fixes land on `develop` and reach the latest release on `main`. Older releases are not supported.

## Reporting a vulnerability

Do not open a public issue, discussion or pull request for a security problem.

Report it privately through GitHub's private vulnerability reporting:

<https://github.com/MarioMH8/resume.mariomh.com/security/advisories/new>

Please include:

- the affected version, commit or package;
- the steps to reproduce the issue, or a proof of concept;
- the impact you expect;
- any fix you have in mind.

You can expect an initial response within seven days. Please give me a reasonable window to ship a fix before disclosing the issue publicly.

## Scope

This policy covers the Astro site, the source code in this repository and the private `@mariomh8/resume` package published to GitHub Packages.

The CV contains personal data. If you find personal information exposed beyond what the site already publishes on purpose, report it through the same private channel so it can be reviewed and removed.
